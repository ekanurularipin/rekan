# REKAN LABEL — Company Profile Website

Website company profile responsif untuk brand modest fashion REKAN LABEL, terinspirasi dari referensi visual yang diberikan.

## Cara menjalankan
1. Ekstrak folder/ZIP.
2. Buka `index.html` di browser, atau jalankan dengan ekstensi Live Server di VS Code.
3. Untuk mengubah nomor WhatsApp, edit URL `https://wa.me/6281234567890` di `index.html` dengan nomor bisnis Anda (format internasional tanpa `+` atau spasi).

## Penyesuaian
- Warna, layout, dan responsive breakpoints: `style.css`
- Menu mobile dan animasi saat scroll: `script.js`
- Konten, tautan, dan metadata SEO: `index.html`
- `assets/referensi-brand.png` adalah gambar referensi yang Anda kirim.

Catatan: foto editorial pada demo menggunakan URL gambar Unsplash sehingga memerlukan koneksi internet. Ganti dengan foto produk/model milik brand sebelum dipublikasikan secara komersial.
